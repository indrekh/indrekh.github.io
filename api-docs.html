ssl.ee API

Hangi sertifikaadi PEM või serveri saadetud täielik sertifikaadiahhel ühe curl-käsklusega. API kasutab täpselt samu andmeallikaid ja sama valikuloogikat nagu veebileht.

01Endpointid

Meetod ja tee Tagastus Kirjeldus
GET /pem?d=<domeen>text/plainÜhe (hetkel aktiivse) lehesertifikaadi PEM
GET /chain?d=<domeen>text/plainTäielik ahel: leht → vahepealsed → juur
GET /history?d=<domeen>application/jsonVäljaandmise ajalugu crt.sh-st (CORS-sõbralik)
GET /?d=<domeen>application/jsonMõlemad PEM-id koos metainfoga
GET /application/jsonEndpointide nimekiri (dokumentatsioon)
GET /healthapplication/jsonLihtne tervisekontroll

02curl-näited

Ainult sertifikaadi PEM
curl "https://ssl.ee/api/pem?d=wikipedia.org"
Ainult täielik ahel
curl "https://ssl.ee/api/chain?d=wikipedia.org"
Salvesta PEM otse faili
curl -o wikipedia.pem "https://ssl.ee/api/pem?d=wikipedia.org"
openssl x509 -in wikipedia.pem -noout -subject -dates
Struktureeritud JSON-vastus
curl "https://ssl.ee/api/chain?d=wikipedia.org&format=json" | jq .count
Väljaandmise ajalugu
curl "https://ssl.ee/api/history?d=wikipedia.org" | jq '.count, .rows[0]'
Kõik korraga (JSON)
curl "https://ssl.ee/api/?d=wikipedia.org" | jq '{certificate, chainCount}'

04Vastused ja veakoodid

PEM-i vastus on text/plain ja lõppeb reavahetusega – sobib otse openssl-ile ja .pem-faili salvestamiseks. JSON-vastus sisaldab alati ok välja.

Kui domeen algab www. ja PEM-i ei leitud, sisaldab pem_not_found veateade vihjet proovida sama domeeni ilma www-eesliiteta.

StaatusKoodTähendus

400invalid_domainParameeter d puudub või domeen ei ole korrektne
404pem_not_foundSelle domeeni kohta pole PEM-i andmeid saadaval
404unknown_endpointTundmatu tee — vaata GET /
405method_not_allowedToetatakse ainult GET ja OPTIONS

05Andmeallikad ja märkused

Ühe sertifikaadi PEM pärineb Certificate Transparency logidest (Cert Spotter) ja on seatud hetkel kehtivale lehesertifikaadile. Täielik ahel pärineb Trustico SSL Toolsist ja näitab just neid sertifikaate, mida server parasjagu teenindab – se võib erineda CT-logis olevast lehest.

Väljaandmise ajalugu pärineb crt.sh-st ja on saadaval otse veebilehel samuti selle Workeri kaudu – nii välditakse crt.sh CORS-piirangut brauseris.

Vastustel on Access-Control-Allow-Origin: * ja Cache-Control: public, max-age=3600. API-võtit pole vaja. Kui soovid piirata kasutamist, lisa Workerisse oma autentimiskontroll.
